# Sales-Analysis-Project
First Data Analyst Project using a given dataset, SQL queries, Python cleaning and PowerBI Visuals
The Dataset used is synthetically generated for demonstration purposes and does not represent real-world data.
The goal of this project is to simulate a real experience as close as possible. Being given a dataset, importing it into SQL to create databases, tables then cleaning everything to be used in Power BI.
This is my 1st project of 3, with each project focusing on different topics
